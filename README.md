# Warasiga (وراسيگا)

Read a receipt, price list or any paper, and get it explained in plain Moroccan Darija (or English). Firebase AI Logic hybrid inference: Chrome on-device Gemini (Prompt API) where available, cloud Gemini otherwise. Built for the Firebase #BuildHybridAI 2026 hackathon.

Live: https://warasiga-9b018.web.app/

Setup: copy `public/firebase-config.example.js` to `public/firebase-config.js` and fill in your own Firebase web config. Serve `public/` statically.
